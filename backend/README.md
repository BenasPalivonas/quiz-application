# Quiz Application — Backend

## API Documentation

API docs are generated by [Scramble](https://scramble.dedoc.co/) and served at `/docs/api`. They're generated from the routes, form requests, and resources directly, so no manual spec maintenance is needed.

## Gemini API Key

Completing a quiz attempt (`POST /api/attempts/{attempt}/complete`) calls the Gemini API to generate personalized AI feedback (`AiFeedbackService`). This requires a `GEMINI_API_KEY` in `.env`:

```ini
GEMINI_API_KEY=your-key-here
GEMINI_MODEL=gemini-3.5-flash-lite
```

## Local Setup (Windows)

PHP on Windows doesn't ship with a CA certificate bundle, so outgoing HTTPS requests (e.g. the Gemini API calls in `AiFeedbackService`) fail with:

```
cURL error 60: SSL certificate OpenSSL verify result: unable to get local issuer certificate (20)
```

To fix it, download a CA bundle and point PHP at it:

1. Download [`cacert.pem`](https://curl.se/ca/cacert.pem) into your PHP install directory (e.g. `C:\php\cacert.pem`).
2. In `php.ini`, set both:
    ```ini
    curl.cainfo = "C:\php\cacert.pem"
    openssl.cafile = "C:\php\cacert.pem"
    ```
3. Restart `php artisan dev` so it picks up the change.

This is a local Windows dev-environment fix only — it doesn't need to be replicated in deployment. Linux hosts (including Laravel Cloud) already have a system CA store wired into OpenSSL/cURL by default.
